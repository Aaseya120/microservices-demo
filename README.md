# Microservices Demo

A practical, buildable workspace demonstrating a Java 21 / Spring Boot 3.3 / Spring Cloud microservices architecture. 
It features a Service Registry, API Gateway, and several domain services interacting via REST, Kafka, and PostgreSQL.

## 🚀 Quick Start

### 1. Prerequisites
- **Java 21**
- **Maven**
- **Docker** and **Docker Compose**

### 2. Start Infrastructure
Start PostgreSQL, Redis, Kafka, and Zookeeper using the provided Docker Compose file:
```bash
docker compose up -d postgres redis kafka zookeeper
```
*(Note: A `micro` database will be created automatically. Tables are generated by Hibernate on first run.)*

### 3. Build the Services
From the root directory, build all microservices:
```bash
mvn clean package -DskipTests
```

### 4. Run the Services
Start the services in the following order. You can run them via your IDE or using Maven from each service's directory:

1. **Service Registry** (Starts on port 8761, accessible at http://localhost:8761)
   ```bash
   cd service-registry && mvn spring-boot:run
   ```
2. **Business Services** (Can be started in any order)
   ```bash
   cd user-service && mvn spring-boot:run
   cd product-service && mvn spring-boot:run
   cd order-service && mvn spring-boot:run
   cd notification-service && mvn spring-boot:run
   ```
3. **API Gateway** (Starts on port 8080)
   ```bash
   cd api-gateway && mvn spring-boot:run
   ```

*Alternatively, to run everything (infrastructure + services) via Docker:*
```bash
docker compose up --build
```

## 🧪 Testing the APIs

Once everything is running, all external traffic should be routed through the API Gateway at `http://localhost:8080`. For testing purposes, you can also hit the services directly on their respective ports.

### Create a User
```bash
curl -X POST http://localhost:8081/api/users \
  -H "Content-Type: application/json" \
  -d '{"email":"jane@example.com","fullName":"Jane Doe","password":"secret123"}'
```

### Create a Product
```bash
curl -X POST http://localhost:8083/api/products \
  -H "Content-Type: application/json" \
  -d '{"name":"Keyboard","description":"Mechanical","price":49.99,"stockQuantity":100}'
```

### Fetch Products
```bash
curl http://localhost:8083/api/products
```

### Create an Order
```bash
# Hitting the order service directly
curl -X POST http://localhost:8082/api/orders \
  -H "Content-Type: application/json" \
  -d '{"userId":"user-123","productId":"prod-456","qty":2}'
```

### Check Service Health
```bash
curl http://localhost:8082/actuator/health
```

## 📦 Project Modules

| Module | Port | Description |
|---|---|---|
| `service-registry` | 8761 | Eureka service registry for service discovery. |
| `api-gateway` | 8080 | Spring Cloud Gateway (routing, rate limiting, circuit breaker). |
| `user-service` | 8081 | Manages user data (PostgreSQL). |
| `product-service` | 8083 | Product catalog with Redis caching. |
| `order-service` | 8082 | Manages orders, coordinates distributed transactions (Saga/Outbox). |
| `notification-service` | 8084 | Consumes Kafka messages to send notifications. |
